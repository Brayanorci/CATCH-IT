# 🎮 CATCH IT! – Atrapa todo

**CATCH IT!** es un videojuego web indie de estilo arcade, desarrollado con HTML, CSS y JavaScript. El jugador controla una canasta que debe atrapar frutas y estrellas que caen desde la parte superior de la pantalla, evitando las bombas para conseguir la mayor puntuación posible.

## 💡 Propuesta del videojuego

El objetivo de CATCH IT! es ofrecer una experiencia de entretenimiento sencilla, divertida y accesible desde un navegador web, sin necesidad de instalar programas adicionales.

La propuesta consiste en un juego de reflejos en el que el jugador debe reaccionar rápidamente para atrapar objetos, administrar sus vidas y superar su propio récord.

## 🕹️ ¿Cómo se juega?

- Atrapa frutas para obtener **10 puntos**.
- Atrapa estrellas para obtener **25 puntos**.
- Evita las bombas: cada una que atrapes te hará perder una vida.
- Comienzas con **3 vidas**.
- Cada 100 puntos alcanzas un nuevo nivel.
- La dificultad aumenta progresivamente.
- Intenta superar tu récord personal.

## 🎮 Controles

| Tecla o control | Acción |
|---|---|
| Flecha izquierda (←) o A | Mover la canasta a la izquierda |
| Flecha derecha (→) o D | Mover la canasta a la derecha |
| Ratón | Mover la canasta siguiendo el cursor |
| Pantalla táctil | Mover la canasta con el dedo |

## ✨ Características

- Interfaz arcade minimalista.
- Generación aleatoria de objetos.
- Detección de colisiones.
- Sistema de puntuación y vidas.
- Niveles y dificultad progresiva.
- Récord guardado en el navegador.
- Efectos de sonido generados con Web Audio API.
- Compatible con computadoras y dispositivos móviles.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura del videojuego.
- **CSS3:** diseño visual e interfaz.
- **JavaScript:** lógica, controles y mecánicas.
- **Canvas API:** representación gráfica del juego.
- **Web Audio API:** efectos de sonido.
- **LocalStorage:** almacenamiento del récord.

## 🚀 Ejecutar localmente

1. Clona este repositorio:

   ```bash
   git clone URL_DE_TU_REPOSITORIO
   ```

2. Entra a la carpeta:

   ```bash
   cd CATCH-IT
   ```

3. Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

No es necesario instalar dependencias.
